Data Preparation · 数据与分析边界

源文件 criteo-uplift-v2.1.csv 共 13,979,592 行；本次建模样本 1,000,000 行，抽样方法：uniform without replacement, random-priority reservoir，随机种子 42。固定采用 train / validation / test = 60% / 20% / 20%，按 treatment × 主结果联合分层；模型均只在 train 拟合，没有 train + validation 重拟合。

研究对象是公开样本中 treatment 分配对结果的 ITT 风格效应。模型仅用 f0–f11 处理前特征；exposure、visit、conversion 不作为特征，也不按曝光或访问行为筛选人群。propensity 在本报告中表示 P(Y=1 | X,T=1) 的结果倾向排序，不表示处理分配概率。

全量扫描发现：缺失/非有限数 0，非二元标签 0，对照组曝光 0，转化但未访问 0；全字段重复指纹 1,259,545。重复指纹只是记录特征诊断，没有 user ID，因此保留原行，不能直接推断重复用户。

与训练集匿名特征向量相同的比例：validation 1.86%、test 1.86%。该检查基于建模时 float32 表示；相同向量不等于同一用户，也不能排除未知用户依赖。

Experiment Diagnostics · 分组与可学习性诊断

全量公开数据计数与外部参考比例 85.00% 的一致性检查：p = 0.999；不能据此验证原始线上实验SRM或证明随机化。 当前训练集处理比例 e = 0.850410 只作为 HT 评估的 plug-in 分配概率，并非已知实验设计参数。

Test Evaluation · 增量排序与 Qini

主比较仍是固定主预算的政策增量；HT AUUC 汇总所有预算，传统 Qini score 用作辅助。二者尺度与归一化不同，不能与其他库的同名分数直接混用；HT 中心面积也不等于传统 Qini score。

本报告的计算定义

zᵢ = TᵢYᵢ/e − (1−Tᵢ)Yᵢ/(1−e)

k = floor(qn), G_HT(q) = (1/n) Σᵢ∈top-k zᵢ；每 10 万人增量 = 100000 × G_HT(q)。

随机政策期望 = (k/n) × mean(z)；HT AUUC = ∫₀¹ G_HT(q) dq；HT 中心面积 = HT AUUC − G_HT(1)/2。

传统曲线 Q_trad(q) = [R₁(q) − R₀(q) × N₁(q)/N₀(q)] / n；Nₐ 为已选前缀内各组人数，Rₐ 为对应正例数。传统 Qini score = ∫₀¹ [Q_trad(q) − q × Q_trad(1)] dq。当前 v2 从原点 (0,0) 开始，对所有 N₀(q) > 0 的前缀点作梯形积分，包括仅包含对照组时的零值点。尚无对照组的前缀曲线值未定义，不作为积分节点；积分从原点线性连接到首个保留点，原始曲线仍保留相应缺失值。未进行“完美排序面积”归一化，因此不能直接等同于其他库中同名的 normalized Qini score。

版本说明：历史 v1 仅保留同时包含处理组和对照组的前缀作积分节点；当前 v2 保留所有已有对照组的前缀，包括仅有对照组的零值点。历史基线与稳定性研究的 v1 结果保持原样，未因本次说明修订而按 v2 重算。

相同分数用独立于 outcome 的固定随机优先级破同分；模型必须在被评估样本之外训练。

Uplift Modeling · S/T/X 与 CATE 校准

获选政策 propensity 不输出 CATE，因此不能做 CATE 校准；这里展示验证集内最优 uplift 模型 s_logistic 的辅助诊断，不能把它视作获选政策。

S 用 X 和 T 拟合一个结果模型；T 分组拟合两个结果模型；X 再用两组伪效应拟合回归器，按训练处理比例加权。X 的 CATE 不直接等于两个结果模型预测之差。四个候选与原超参数保持不变，预处理仅在 Train 拟合。

Conclusion · 推断边界与下一步

全量/分箱 ATE 区间使用未合并方差的正态近似；ATE 双侧 p 值使用零假设下合并比例的 z 检验，因此两者并非严格有限样本对偶，稀疏分箱尤其需要谨慎解释。p 值不表示零假设为真的概率。

C2ST 的 p 值是 AUC 上尾检验：p = (1 + #{AUC_perm ≥ AUC_obs}) / (B + 1)，本次 B = 499，未校正 p 的最小可能值为 0.002，最大为 1；两模型使用 Holm 校正。ATE 的渐近 p 值不是该离散网格上的值。政策表只报告点估计和区间，没有把 bootstrap 区间换算为未经定义的 p 值。

公开匿名样本的离线 ITT 结论不能直接外推到当前线上人群、曝光效果或盈利效果。实际收益还需要成本、转化价值、可触达条件及线上随机验证。

  1. 在资源允许时扩到 500 万样本或全量，保留独立留出集；本报告没有宣称已完成该规模训练。
  2. 本次已按既定多随机种子方案评估训练与选择稳定性；不能反复依据当前测试结果调参。
  3. 对相同匿名特征向量按组拆分作敏感性分析，并比较结果；这不是用户级去重，结果见本报告 Stability Analysis。
  4. 补充成本/价值场景与上线门槛，冻结候选政策后开展新的线上随机实验。
